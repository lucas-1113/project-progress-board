# 项目进度看板

一个无后端、数据仅保存在当前浏览器的项目进度 PWA。每个主项目可以包含多个子项；每个子项固定拥有 15 个可编辑里程碑。

## 数据与隐私

- 项目、备注和图片保存在浏览器 IndexedDB，不会上传到服务器。
- 通过普通 `.xlsx` Excel 备份在不同电脑或浏览器之间迁移数据。
- 公开站点代码不包含真实项目数据；初始项目资料通过单独发送的 Excel 文件导入。

## 主要功能

- 15 阶段密集看板、筛选与项目统计
- 自动紧凑模式，根据窗口高度和当前项目行数适配一屏展示
- 主项目 / 子项层级和项目详情抽屉
- 项目进度 / 已完成双看板；全部子项达到 100% 后可归档并随时恢复
- 里程碑状态、备注、强调色与自动完成度
- 每个项目最多 8 张本机图片
- 完整 Excel 导入导出和离线 PWA

## 开发与构建

```bash
npm run dev
npm run build
```

生产发布前必须确认业务数据和 Excel 备份文件没有进入 Git 仓库。
